M MStudo Desktop

Kết nối với tài khoản studio

Mở mstudo → MStudo Desktop trên trình duyệt (tài khoản chủ studio), bấm “Kết nối thiết bị mới” rồi dán mã kết nối và địa chỉ máy chủ vào đây.

Chọn thư mục lưu dữ liệu

Hợp đồng (PDF + Word) và các file Excel sao lưu sẽ tự động lưu vào đây. Có thể đổi vị trí bất cứ lúc nào trong phần cài đặt.

Chưa chọn thư mục
📁 HopDong/ — mỗi hợp đồng 1 thư mục (PDF + Word, bản mới khi ký lại)
📁 KhachHang/ · BaoGia/ · ChiTieu/ · Luong/ · LichHen/ · NhanVien/ — Excel hằng ngày
📁 SaoLuu/ — bản JSON đầy đủ để khôi phục · tự dọn file cũ hơn 30 ngày

    Kết nối Google Drive tại mstudo (web) › Khách hàng › Đồng bộ Drive. Chọn thư mục gốc trên máy để chứa ảnh/video các hợp đồng (mỗi hợp đồng 1 thư mục con, tự tải lên Drive).

    Đăng nhập giao diện studio

    Không đăng nhập được (kẹt ở trang đăng nhập, quay vòng, hoặc còn phiên của tài khoản cũ)? Bấm Đăng xuất / xóa cookie — máy chủ xóa cookie phiên rồi mở lại trang đăng nhập.
